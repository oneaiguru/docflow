# Сервис `interactions`

Папка `server/src/services/interactions` в проекте `oneaiguru/AZ_trasko`
реализует сервис управления взаимодействиями между микросервисами. Он
использует PostgreSQL как хранилище и публикует события в шину сообщений.
Основные возможности оригинального сервиса:

* **Создание взаимодействия** – запись информации о запросе от одного
  сервиса другому с возможностью указания родителя, уникальности
  (singleton), отложенной обработки (`processAt`/`processIn`) и
  немедленного завершения.
* **Получение данных** – методы `get`, `getChildren` и `getByMessageId`
  позволяют читать отдельные взаимодействия, искать дочерние записи и
  выбирать элементы по идентификатору сообщения.
* **Обновление состояния** – внутренний метод `_update` отмечает
  завершение, ошибки, отмену и планирование следующей обработки.
* **Обработка очереди** – функция `process` выбирает из БД элементы,
  готовые к выполнению, блокирует их, запускает обработчик, фиксирует
  ошибки и публикует события о старте и завершении.
* **Вспомогательные модули** – `_rowToInteraction`, `_states`,
  `_defaults`, `_fixServiceName` и др. обеспечивают преобразование данных
  из БД, перечисления состояний и настройки таймингов.

В рамках данного репозитория подготовлена Python-версия сервиса,
хранящая данные в памяти. Реализация поддерживает ключевые операции:

* создание и чтение взаимодействий;
* обновление их состояния (`update`), включая планирование следующей
  обработки и фиксацию ошибок;
* обработку очереди через метод `process`;
* простые транзакции — несколько изменений можно сгруппировать в
  контекст `with service.transaction()`, который коммитит или
  откатывает изменения целиком.

Тесты иллюстрируют работу API и возможные ошибки при обработке.

## Пример использования

```python
from interactions import InteractionService

svc = InteractionService()
svc.create(from_service="web", to_service="worker", action="send_mail")

def process(ia):
    print(f"processing {ia.id}")

svc.process(to_service="worker", action="send_mail", processor=process)
```

При запуске пример создаёт запись во внутреннем хранилище и немедленно
передаёт её обработчику `process`, после чего состояние взаимодействия
меняется на `completed`.
